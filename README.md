# Mechinno Management Panel

پنل مدیریتی فارسی و راست‌به‌چپ برای مرکز نوآوری دانشکده مکانیک. PHP ساده بدون Composer، مناسب cPanel.

## ویژگی‌ها

- رابط کاربری روشن با تم آبی کم‌رنگ و فونت Vazirmatn
- **پنل خالی** — فقط ۲۴ میز از قبل ساخته می‌شود؛ بقیه داده‌ها را خودتان وارد می‌کنید
- داشبورد با خلاصه ماه، اقدامات پیشنهادی، نمودار شارژ و بدهی
- مدیریت نهادها (تیم / شرکت / دانشجو)، اعضا، میزها، کمدها، شارژ و مالی
- شناسه‌های خودکار (`T-001`, `M-001` و …)
- پروفایل کامل هر نهاد (میز، اعضا، کمد، شارژ، واریز)
- صفحه‌بندی جداول
- محاسبه خودکار شارژ از نرخ سالانه (دکمه در بخش شارژ)
- ویرایش دستی مبالغ شارژ و تراکنش‌ها
- خروجی Excel و گزارش چاپی PDF

## نیازمندی‌ها

- PHP 8.1+
- PDO (MySQL یا SQLite)
- ZipArchive و SimpleXML (فقط برای خروجی Excel)

## نصب روی cPanel

1. دیتابیس MySQL و کاربر بسازید (و کاربر را به دیتابیس وصل کنید).
2. فایل‌های پروژه را آپلود کنید.
3. `config.sample.php` را به `config.php` کپی کنید.
4. در `config.php` این مقادیر را **حتماً** عوض کنید:
   - `db.database` / `db.username` / `db.password` (نه مقادیر `YOUR_…` یا `CHANGE_ME`)
   - `auth.password` و در صورت نیاز `auth.viewer_password`
   - `app_secret` (یک رشته تصادفی طولانی)
   - `install_enabled` را برای نصب اولیه `true` بگذارید
5. مستقیم `https://your-domain.com/install.php` را باز کنید (برای نصب اول نیازی به ورود قبلی نیست).
6. نام کاربری/رمز `auth` همان config را وارد کنید و **بازنشانی کامل پنل** را بزنید.
7. بعد از نصب موفق، `install_enabled` را `false` کنید و در صورت تمایل `install.php` را حذف کنید.
8. پنل: `https://your-domain.com/index.php`

اگر پیام «اتصال به دیتابیس برقرار نشد» دیدید، صفحهٔ نصب باز می‌ماند و جزئیات مشکل را نشان می‌دهد — معمولاً نام دیتابیس/کاربر/رمز هنوز مقدار نمونه است.

**نیازی به پاک کردن دستی دیتابیس نیست.** اگر داده قبلی وجود داشته باشد، نصب مجدد همه رکوردها را پاک و پنل خالی (۲۴ میز) می‌سازد.

### بعد از نصب — فایل‌های قابل حذف

| حذف کنید | دلیل |
|----------|------|
| `install.php` | جلوگیری از نصب مجدد تصادفی |

| نگه دارید | دلیل |
|-----------|------|
| `config.php` | اتصال دیتابیس و ورود |
| بقیه فایل‌های پنل | اجرای عادی |

## شروع کار در پنل خالی

1. **نهادها** — تیم، شرکت یا دانشجو ثبت کنید
2. **اعضا** — هر عضو را به نهاد و میز(ها) وصل کنید
3. **کمدها** — شماره کمدها را خودتان اضافه کنید
4. **شارژ** — نرخ سالانه تعریف کنید، سپس محاسبه خودکار یا ثبت دستی
5. **مالی** — درآمد، هزینه و دریافت شارژ از نهادها (مرکز طلبکار، نهاد بدهکار)

برای پاک کردن همه داده و شروع دوباره: **بازنشانی پنل** در منو یا `install.php`.

## مسیرهای اصلی

| مسیر | کاربرد |
|------|--------|
| `index.php` | پنل اصلی |
| `install.php` | نصب / بازنشانی پنل خالی |
| `api.php?resource=summary` | API داشبورد |
| `api.php?resource=team-profile&id=1` | پروفایل نهاد |
| `POST api.php?resource=recalculate-charges` | محاسبه خودکار شارژ |
| `export.php?report=all` | خروجی Excel |
| `report.php` | گزارش مالی قابل چاپ |

## API صفحه‌بندی

```text
GET api.php?resource=members&page=2&per_page=25
```

پاسخ:

```json
{
  "rows": [...],
  "total": 0,
  "page": 2,
  "per_page": 25,
  "pages": 1
}
```

## شارژ و نرخ

- نرخ‌ها در بخش **شارژ → نرخ‌های سالانه** تعریف می‌شوند (مبلغ **ماهانه** به ازای هر میز).
- مبالغ شارژ را می‌توان دستی ویرایش کرد.
- دکمه **محاسبه خودکار از نرخ** شارژ ماهانه را از تعداد میز × نرخ ماهانه هر میز محاسبه می‌کند.

## امنیت و پایداری داده

`.htaccess` دسترسی به `config.php`، `src/` و `data/` را محدود می‌کند. رمز قوی برای پنل و دیتابیس انتخاب کنید.

- قبل از لانچ، رمزهای `config.php` را از مقادیر نمونه عوض کنید، `app_secret` را تصادفی کنید و `install.php` را بعد از نصب حذف کنید.
- پشتیبان کامل از مسیر `backup.php` (دانلود JSON و بازیابی با تأیید). فایل پشتیبان شامل رمزهای ورود نهاد و تنظیمات پیامک است؛ فقط در محل امن نگه دارید.
- حذف نهاد، داده‌های وابسته (اعضا، شارژ، تراکنش‌ها، قرارداد، درخواست‌ها) را هم پاک می‌کند و میز/کمد را آزاد می‌کند.
- برای هر نهاد/سال/ماه فقط یک ردیف شارژ نگه داشته می‌شود؛ دفتر معین و لیست‌ها صفحه‌بندی دارند تا با رشد داده پایدار بمانند.

### Nginx (نمونه)

اگر به‌جای Apache از Nginx استفاده می‌کنید، معادل `.htaccess` را اعمال کنید:

```nginx
location ~ /(config\.php|config\.sample\.php)$ { deny all; }
location ~* \.(xlsx|sqlite3|db|sql|log|bak|env)$ { deny all; }
location ~ ^/(src|data|tests|scripts|tools|app)(/|$) { deny all; }
```
